# ガウス過程回帰の解説動画（基礎から予測まで）— 生成元

研修用に、ガウス過程回帰を基礎から予測まで約14分で解説する動画 `../ガウス過程回帰_基礎から予測まで.mp4` の生成元です。
「関数に正規分布を置く → カーネル → 条件づけて予測する → ハイパーパラメータを決める → 実務での使い方と注意」の流れで、理論（式）と図解（グラフ）を交互に進めます。
データ3点での計算例と、実務で使うときの手順も入れています。動画の中では、ほかの動画との関係には触れていません。

- 1920×1080、30fps、H.264、字幕と読み上げ音声つき（Mac の声 Kyoko、AAC 24kHz・48kbps）
- 作り方は、ほかの解説動画（`../ガウス過程回帰とニューラルネット_無限幅の対応_src/` など）と同じです。時刻 t を入れると必ず同じ絵が出るページを作り、ヘッドレス Chrome で1コマずつ撮って ffmpeg で MP4 にします。ガウス過程の計算 `js/gp-math.js` は、`../ガウス過程回帰_加法カーネルと周期カーネル_src/` と同じものです。

## 構成（22場面）

| 章 | 理論 | 図解 |
|---|---|---|
| はじめに・ポイント | 題名と目次、要点4つ | 4つのカードに小さな図 |
| 1 全体像 | 回帰の問題、関数そのものに分布を置く、用語、使いどころ | 事前分布のサンプル → データ → 事後分布 → 平均と帯 |
| 2 多変量正規分布 | 平均・共分散行列・相関係数、条件付き分布の式、数値例（ρ = 0.8 で f₁ = 1） | 相関を変えた点の雲、f₁ = 1 の帯の点と f₂ の分布 |
| 3 ガウス過程とカーネル | 定義、RBF の式、σ_f と ℓ、距離ごとの値の表 | 近い2点・離れた2点の楕円、点を増やすと関数になる、ℓ = 0.3 と 2 のサンプル、カーネル行列の色（ℓ = 0.5 と 2） |
| 4 Matérn カーネル | ν = 1/2・3/2・5/2 の式、微分できる回数、選び方 | ν ごとのサンプル（同じ乱数） |
| 5 予測の式 | 同時分布 → μ*・σ*²、α と山の和、分散は y によらない、データ3点での計算例（K + σ²I、α、k*、μ*、σ*²） | データを1点ずつ加える、αᵢ k(x, xᵢ) の山、事後サンプル |
| 6 ノイズとハイパーパラメータ | σ_n の役割、対数周辺尤度（当てはまり＋複雑さの罰則）、選ばれた値 | ℓ = 0.2 → 3 → 最大の 0.93 と、周辺尤度の曲線と2つの項、σ_n = 0.02 → 0.6 → 0.15 |
| 7 実務での使い方と注意 | 計算量、近似、入力ごとの長さスケール、外挿、使い方の手順5つ（標準化 → カーネル → 周辺尤度 → 予測と帯 → 確かめる）、ツールの例 | x = 6〜9 の外挿、データ数と計算時間の比 |

## 例のデータと数値

- データ：x = 0.4, 1.1, 1.9, 2.6, 3.8, 4.5, 5.6 の7点、y = sin(1.3x) + 0.35 cos(2.9x + 0.4) ＋ ノイズ（標準偏差 0.12、種を固定した乱数）。説明用に作ったもので、実在のデータではありません
- RBF カーネルのハイパーパラメータは、対数周辺尤度の格子探索（ℓ 80 × σ_f 40 × σ_n 40）で選び、ℓ ≈ 0.93、σ_f ≈ 0.69、σ_n ≈ 0.15 になりました
- 3点の計算例は x = 1, 2, 4、y = 0.9, 0.6, −0.7、σ_f = 1、ℓ = 1、σ_n² = 0.01 で、x* = 3 の予測は平均 −0.198、分散 0.300
- 画面の数値（相関係数、RBF の値、条件付き分布の平均と分散、選ばれた値、3点の計算例）は手で書かず、計算した値を表示しています。読み上げ原稿にも同じ数値を書いているので、データを変えたら原稿も直します

## 実行方法

必要なもの: Node.js（24 で確認）、ffmpeg、Google Chrome（ヘッドレスで使う）。

```bash
npm install
node tools/render.mjs info                   # 尺と場面の時刻表
node tools/render.mjs sheet 8 --scene 5V     # 1場面を8コマ並べた確認画像（out/sheet-5V.png）
node tools/render.mjs stills 120,500         # 指定した秒の原寸画像（out/still-<秒>.png）
node tools/check-layout.mjs                  # 文字のはみ出しを調べる
node tools/render.mjs serve                  # ブラウザで確認するための URL を表示
```

音声つきの動画は、次の順で作ります（声の長さで字幕の時間が変わるため、映像は声を作ったあとに書き出す）。

```bash
node tools/render.mjs voice                  # 原稿を音声にする（narration/clips/）、長さを narration/seconds.js に書く
caffeinate -i node tools/render.mjs video gpr-basics   # 映像を書き出す（out/gpr-basics.mp4。既定は2並列）
node tools/render.mjs mux gpr-basics          # 音声を字幕の時刻に並べて重ねる（out/gpr-basics-voice.mp4）
```

できた `out/gpr-basics-voice.mp4` を、親フォルダの `ガウス過程回帰_基礎から予測まで.mp4` として置きます。

## 注意事項

- 認証情報や環境変数は使いません。
- `out/`、`narration/clips/`、`node_modules/` は Git に含めません。
- 読み上げは Mac の `say` コマンドを使うため、`voice` は Mac でだけ動きます。読み方は耳では確認していません。声の比較で分かった読み違い（「300回」が「さんびゃくかい」、「良し悪し」、「右上がり」）は、かな・カタカナに直すか言いかえています。MATLAB・fitrgp・scikit-learn はカタカナで書いています。
- メモリが 8GB の Mac では、書き出しは2並列にします（4並列はスワップでディスクの空きが尽きることがある）。書き出しの途中でスリープすると撮影が止まることがあるため、`caffeinate -i` を付けて実行します。
