# 状態空間モデルとカルマンフィルターの解説動画（全3回）— 生成元

初学者向けに、状態空間モデルとカルマンフィルターを3回に分けて解説する動画の生成元です。
各回とも、理論（式）と図解（グラフ）を交互に進めます。完成した動画は、親フォルダに置いています。

| 回 | 動画（親フォルダ） | 長さ | 内容 |
|---|---|---|---|
| 第1回 | `状態空間モデルとカルマンフィルター_第1回_状態空間モデル入門.mp4` | 18分00秒 | 見えない状態と観測、2本の式、正規分布、Q と R、行列で書く、いろいろなモデル、3つの推定問題 |
| 第2回 | `状態空間モデルとカルマンフィルター_第2回_カルマンフィルターのしくみ.mp4` | 17分51秒 | 2つの情報を混ぜる、予測と更新、カルマンゲイン、手計算、指数平滑との関係、行列の5本の式、位置から速度を推定 |
| 第3回 | `状態空間モデルとカルマンフィルター_第3回_カルマンフィルターを使いこなす.mp4` | 17分53秒 | イノベーションでの確認、尤度で Q・R を決める、欠測と予測、平滑化、非線形への拡張（EKF・UKF・粒子フィルター）、実務の手順と注意 |

- 1920×1080、30fps、H.264、字幕と読み上げ音声つき（Mac の声 Kyoko、AAC 24kHz・48kbps）
- 前提にしている知識は、平均・分散と、行列の掛け算の初歩です。正規分布の性質と行列の掛け算は、第1回の中で図と数値で確かめます
- 作り方は、ほかの解説動画（`../ガウス過程回帰_基礎から予測まで_src/` など）と同じです。時刻 t を入れると必ず同じ絵が出るページを作り、ヘッドレス Chrome で1コマずつ撮って ffmpeg で MP4 にします。画面の見た目（明るい方眼ノート）も同じです
- 初学者向けなので、読み上げは速めていません（`say` の速さ 200、動画の速さ 1 倍）

## 構成

### 第1回 状態空間モデル入門（26場面）

| 章 | 理論 | 図解 |
|---|---|---|
| はじめに・ポイント | 題名、3回の構成、目次、要点4つ | 4つのカードに小さな図 |
| 1 見えない状態と、見える観測 | 状態と観測、2本の式、使われている分野 | 温度計の読み（点）と本当の温度（線）、移動平均の限界 |
| 2 2本の式 | ローカルレベルモデル（状態方程式・観測方程式） | 式のとおりにデータを作る、鎖の図 |
| 3 ノイズを正規分布で表す | 平均と分散、±2σ、分散の足し算と定数倍 | ヒストグラム、足すと分散は足し算、ランダムウォークの広がり |
| 4 Q と R | 2つのノイズの役割、比で決まる | Q・R を変えたデータ、Q の見立てと推定 |
| 5 行列で書く | 位置と速度、F・H、一般形、数値での掛け算 | 台車の位置（観測）と速度（見えない） |
| 6 いろいろなモデル | ローカルレベル、トレンド、AR(1)、季節 | 成分の足し合わせ、F = 1 と 0.9 の違い |
| 7 3つの問題 | フィルタリング・予測・平滑化 | 同じデータで3つを比べる |
| まとめ・参考文献 | 要点5つ、次回の案内 | |

## 例のデータと数値

説明用に式と乱数（種を固定）で作ったもので、実在のデータではありません。

- 例A 部屋の温度（ローカルレベルモデル）：100点、Q = 0.0625、R = 1、最初の温度 20 ℃。フィルターの最初の推定は 20 ℃・分散 4
- 例B 台車（等速モデル、位置だけを観測）：40点、時間の刻み 1 秒、速度のノイズの分散 0.01、観測ノイズの分散 4。フィルターの最初の推定は位置 0・速度 0、分散は 25 と 4
- 手計算の例：Q = 1、R = 4、最初の推定 20・分散 3、観測 22、19、23
- 非線形の例：レールから 2 m 離れたセンサーが、台車までの距離 √(p² + 2²) を測る。EKF で台車を追う場面では、センサーを 20 m 地点の横に置く（観測ノイズの分散 0.25）
- 画面の数値（ずれの大きさ、ゲイン、尤度が最大の点、はみ出しの回数など）は手で書かず、計算した値を表示しています。読み上げ原稿の数値も、同じ計算値から作っています
- `node tools/check-math.mjs` で、1次元の式と行列の式が一致すること、平滑化の結果が「全部の観測を一度に使う条件づけ」と一致することなどを確かめています

## 実行方法

必要なもの: Node.js（24 で確認）、ffmpeg、Google Chrome（ヘッドレスで使う）。

```bash
npm install
node tools/check-math.mjs                              # 計算の確認
node tools/render.mjs info --page ssm-1.html           # 尺と場面の時刻表
node tools/review.mjs ssm-1.html                       # 全場面の確認画像（out/review-ssm-1-*.png）
node tools/render.mjs sheet 8 --scene 5V --page ssm-2.html   # 1場面を8コマ並べた確認画像
node tools/check-layout.mjs ssm-1.html                 # 文字のはみ出しを調べる
node tools/render.mjs serve --page ssm-1.html          # ブラウザで確認するための URL を表示
```

音声つきの動画は、回ごとに次の順で作ります（声の長さで字幕の時間が変わるため、映像は声を作ったあとに書き出す）。`ssm-1` を `ssm-2`・`ssm-3` に変えると、ほかの回になります。

```bash
node tools/render.mjs voice --page ssm-1.html                         # 原稿を音声にする（narration/clips/ssm-1/）
caffeinate -i node tools/render.mjs video ssm-1 --page ssm-1.html     # 映像を書き出す（out/ssm-1.mp4）
node tools/render.mjs mux ssm-1 --page ssm-1.html                     # 音声を重ねる（out/ssm-1-voice.mp4）
```

できた `out/ssm-1-voice.mp4` を、親フォルダへ上の表の名前で置きます。

## 注意事項

- 認証情報や環境変数は使いません。
- `out/`、`narration/clips/`、`node_modules/` は Git に含めません。
- 読み上げは Mac の `say` コマンドを使うため、`voice` は Mac でだけ動きます。読み方は耳では確認していません。数式の記号は読み方（エックスティー、キュー、アールなど）に直し、読み違えやすい語（分散 → ぶんさん、値 → あたい、帯 → おび、平滑化 → へいかつか、尤度 → ゆうど、行列 → ぎょうれつ、欠測 → けっそく など）はかなで書いています。`tools/check_reading.py` の声の比較で疑いが出た語（欠測、上の行・下の行）は、かなに直しました。
- メモリが 8GB の Mac では、書き出しは2並列にします。書き出しの途中でスリープすると撮影が止まることがあるため、`caffeinate -i` を付けて実行します。
