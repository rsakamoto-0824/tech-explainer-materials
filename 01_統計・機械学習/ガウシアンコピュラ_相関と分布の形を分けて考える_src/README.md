# ガウシアンコピュラの解説動画（YouTube向け）— 生成元

初学者向けに、ガウシアンコピュラを約14分半で解説する動画 `../ガウシアンコピュラ_相関と分布の形を分けて考える.mp4` の生成元です。
「分布の形」と「つながり方」を分けて考える、という1本の筋で、理論（式）と図解（グラフ）を交互に進めます。

- 1920×1080、30fps、H.264、字幕と読み上げ音声つき（Mac の声 Kyoko）
- YouTube向けの動画なので、[Remotion](https://www.remotion.dev/) で作っています（ほかの解説動画はヘッドレス Chrome で撮る方式）。

色と大きさは `src/theme.ts` で決まります。

## 例のデータと数値

- 混雑率（0〜1）はベータ分布 Beta(3, 2)、待ち時間（分）は平均20分の指数分布、つながり方は相関係数 0.7 のガウシアンコピュラ。400件。説明用に作ったもので、実在のデータではありません。
- 追いかける1点は z = (1.2, 0.6)。u = (0.88, 0.73)、混雑率 0.85、待ち時間 約26分。
- 生データの相関係数は 0.64、待ち時間の対数をとると 0.71、正規スコアの相関係数は 0.72。
- すその比較は、ガウシアンコピュラと自由度3の t コピュラ（どちらも相関係数 0.7、5000点）。両方が上位1%に入る点は、理論の期待値が 13.3個と 23.2個で、例の点は 13個と 23個になる乱数の種を選んでいます。t コピュラのすその依存係数は 0.45。
- 画面の数値は手で書かず、計算した値を表示しています。台本（`src/script.ts`）にも同じ数値を書いているので、データを変えたら `node tools/numbers.ts` の結果に合わせて台本も直します。

## 実行方法

必要なもの: Node.js（24 で確認）、ffmpeg、Mac（読み上げに `say` を使うため）。

```bash
npm install
npm run dev                      # プレビュー（Remotion Studio）を開く
node tools/check-captions.ts     # 字幕が2行に収まるかを調べる
tools/sheet.sh S5V               # 場面の確認画像（out/sheet-S5V.png）
```

動画は、次の順で作ります（声の長さで場面の長さが決まるため、先に声を作る）。

```bash
npm run voice                    # 台本を音声にする（public/voice/）、長さを src/timings.json に書く
caffeinate -i npm run render     # 書き出す（out/gaussian-copula.mp4）
```

できた `out/gaussian-copula.mp4` を、親フォルダの `ガウシアンコピュラ_相関と分布の形を分けて考える.mp4` として置きます。

## 注意事項

- 認証情報や環境変数は使いません。
- `out/`、`public/voice/`、`narration/clips/`、`node_modules/` は Git に含めません。
- 場面の長さと動きの時刻は、読み上げの長さから計算しています。そのため、Remotion Studio の画面で時刻を直接動かす編集には向きません。直すときは台本（`src/script.ts`）か場面のファイルを書きかえます。
- 読み方は耳では確認していません。`tools/check_reading.py` で疑いが出た語（表データ、5000個、行列、400件 など）は、`src/script.ts` の `READINGS` でかなに直しています。
- メモリが 8GB の Mac では、書き出しは2並列にします。
- Remotion は、個人と小さな組織は無料で使えますが、会社で使う場合はライセンスの確認が必要です（https://www.remotion.dev/docs/license）。
