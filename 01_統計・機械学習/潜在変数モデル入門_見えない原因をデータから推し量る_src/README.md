# 潜在変数モデル入門（YouTube 向けの解説動画）— 生成元

初学者向けに、潜在変数モデルの考え方を約19分で解説する動画 `../潜在変数モデル入門_見えない原因をデータから推し量る.mp4` の生成元です。
式で確かめる「理論」と、グラフで確かめる「図解」を交互に進めます。

- 1920×1080、30fps、H.264、字幕と読み上げ音声つき（Mac の声 Kyoko、AAC 96kbps・モノラル）、18分52秒
- YouTube 向けの動画なので、Remotion（React で動画を作る道具）で作っています
- 図の数値は、説明用に乱数で作った合成データを、このフォルダのスクリプトで計算したものです（実測のデータではありません）

## 例の設定

- **身長の例（第1〜5・8章）**：400人。グループ1は平均 158 cm・標準偏差 5.2 cm、グループ2は平均 172 cm・標準偏差 5.6 cm、割合は半分ずつ。乱数の種 7
- **点数の例（第6章）**：300人。数学 = 60 + 11 z + ノイズ、理科 = 58 + 9 z + ノイズ（ノイズの標準偏差 6）、z は標準正規分布。乱数の種 21

## 計算で分かったこと

- EM アルゴリズムは、出発点（中心 150 cm と 160 cm）から 162 回で収束。中心は 157.8 cm と 172.2 cm、割合は 0.46 と 0.54
- 負担率の大きいほうに振り分けたときの正解率は 91.8%
- BIC は K = 2 で最小（2889.7、2871.9、2882.2、2893.8、2911.1）
- 出発点を30通り試すと、対数尤度の低い答えに着いたのは K = 2 で 3 回、K = 3 で 21 回
- 割合と幅を固定した対数尤度の地形には、頂上が2つある（158.3, 172.6 と 172.6, 158.3。番号が入れ替わっただけの同じ答え）
- 点数の例で、推定した z と本当の z の相関は 0.92

## 実行方法

必要なもの: Node.js（24 で確認）、ffmpeg、macOS（読み上げに `say` コマンドの声 Kyoko を使う）。

```bash
npm install
```

```bash
npm run data        # 数値を計算して src/data.json に書く
npm run voice       # 読み上げ音声（public/voice/）と時刻表（src/timeline.json）を作る
npm run dev         # Remotion Studio でプレビューする
node tools/stills.mjs 5V 6V     # 指定した場面の確認画像を out/stills/ に書く
npx remotion render LatentVariableModels out/latent-variable-models.mp4   # MP4 に書き出す（約15分）
```

書き出したままだと音声が大きい（約320kbps）ので、音声だけ軽くしてから、親フォルダに置きます（映像は変えません）。

```bash
ffmpeg -i out/latent-variable-models.mp4 -c:v copy -c:a aac -b:a 96k -ac 1 -movflags +faststart ../潜在変数モデル入門_見えない原因をデータから推し量る.mp4
```

## 注意

- 読み上げの音声（`public/voice/`）はリポジトリに含めていません。はじめに `npm run voice` を実行してください
- 字幕を直したら、`npm run voice` で音声と時刻表を作り直してから書き出します（場面の長さは音声の長さで決まります）
- 字幕の数値は手で書いています。データを作り直したら、`npm run data` の表示と見比べて `src/script.ts` も直します
- 読み上げの読み方は、原稿の文字で点検しましたが、耳では確かめていません
- 認証情報は使っていません。環境変数の設定は不要です
- Remotion は、個人と小規模な組織は無料で使えます。会社で使う場合は、ライセンスの条件（https://www.remotion.dev/docs/license）を確認してください
