# 技術解説資料

Claude Code・Codex のセッションで作った、特定のアプリに属さない汎用の解説資料をまとめて保管するリポジトリ。
概念・手法の解説スライド（PPTX）、技術調査レポート、企業・業界分析、設定手順書と、それらの生成スクリプト・元データを置く。

## フォルダ構成

| フォルダ | 内容 |
|---|---|
| `01_統計・機械学習/` | 統計・機械学習の手法の解説（因果フォレスト、潜在変数モデル、ベイズ最適化、AIC・BIC、実験計画法など） |
| `02_AI・開発ツール/` | AI・開発ツールの解説、図の作例 |
| `03_PowerBI・PowerPlatform/` | Power BI・Power Platform の解説 |
| `04_露光・Overlay/` | 露光・重ね合わせ（Overlay）制御の解説 |
| `05_文章・UIの作法/` | 文章・UIの作法 |
| `06_英語学習/` | 英語学習 |
| `07_環境構築・設定手順/` | 特定のリポジトリに属さない設定手順書 |
| `08_企業・業界分析/` | 企業・事業・業界の分析（SWOT・PEST、競合・市場の調査） |

1つの資料が複数のファイルからなる場合は、分野フォルダの中に資料ごとのフォルダ（`<資料名>_src/` など）を作ってまとめている。

## 資料の作り直し方

各資料の生成スクリプトと元データは、資料と同じフォルダ（`_src` フォルダなど）にある。
手順は各フォルダの README や生成スクリプトの冒頭のコメントを参照する。

- JavaScript（pptxgenjs）で作る資料は、`package.json` のあるフォルダで `npm install` を実行してから生成スクリプトを動かす（`node_modules/` はリポジトリに含めない）。
- 生成スクリプトの出力先は、スクリプトのある場所を基準にしている。

## 注意事項

- 生成済みのPPTX・PDF・画像もリポジトリに含めている。
- `sources/` フォルダには、参考文献として保存した第三者の文書（年次報告書・Webページなど）が含まれる。**このリポジトリは公開（Public）にしない。**
- Zotero 取り込み用の `manifest.json` などには、このPC上のファイルの場所（絶対パス）が書かれている。別のPCでは場所を読み替える。
- 認証情報は使用していない。環境変数の設定は不要。
- Gitで管理している資料リポジトリ（LaTeXレポートなど）は、このフォルダではなく個別のリポジトリで管理する。
