AIトークン節約ガイド
Claude（Opus / Sonnet）・GPT-5.3〜5.5・GitHub Copilot 対応版

AIサービスの利用量は「トークン」や「リクエスト」という単位で計算されます。このレポートでは、Claude、GPT-5.3〜5.5、GitHub Copilotの3つを対象に、専門知識がなくても実践できる節約ポイントを解説します。（料金情報は2026年7月時点の調査に基づきます）

1. はじめに：トークンとは

トークンは、AIが文章を処理するときの「文字のかたまり」の単位です。日本語ではおおよそ1文字＝1〜2トークンが目安です。

  • 入力トークン：あなたが送る文章＋過去の会話履歴＋読み込んだファイルの中身
  • 出力トークン：AIが返す文章（入力より単価が高い。Claude・GPTとも約5〜6倍）
大事なポイント：AIとの会話は「毎回、過去の履歴を全部送り直す」仕組みです。会話が長くなるほど、1回の質問で消費するトークンが雪だるま式に増えます。これはClaudeでもGPTでも共通です。なお、GitHub Copilotだけは課金単位が「トークン」ではなく「リクエスト回数×モデル係数」という別方式です（第5章で解説）。

2. 全サービス共通の節約原則

どのサービスでも効く、普遍的な5原則です。

原則理由
① 作業の重さに合ったモデルを選ぶ最上位モデルと標準モデルで料金が2〜7倍違う
② 会話を短く保つ・話題ごとに区切る履歴は毎回送り直されるため、長い会話ほど高くつく
③ 最初の指示を具体的にまとめる聞き返しのやりとり（＝追加消費）が減る
④ 読ませる資料・範囲を絞るファイル丸ごとは入力トークンを大量消費
⑤ 出力形式を指定する（簡潔に・変更箇所だけ等）出力トークンは入力より単価が高い

3. Claude（Opus / Sonnet）

料金の目安（100万トークンあたり）

モデル入力 / 出力向いている作業
Opus 4.8$5 / $25複雑な設計・大きな実装・長時間の自律作業
Sonnet 5$3 / $15日常的なコーディング・文書作成・分析
Haiku 4.5$1 / $5簡単な質問・分類・要約などの軽い作業

Claude特有の節約ポイント

  • プロンプトキャッシュ：同じ会話を続けている間、履歴の先頭部分は約10分の1の割引価格で再利用されます。有効期限は約5分。連続作業は間を空けず、同じ会話・同じモデルで進めるのが得です
  • ✕ 途中でモデルを切り替える：OpusとSonnetのキャッシュは別々なので、切り替えた直後は割引が効きません
  • Claude Codeのコマンド：/clear（話題が変わったら履歴リセット）、/compact（長い会話を要約して圧縮）、/model（モデル切り替え）
  • CLAUDE.mdの整理：ルールファイルは毎回自動で読み込まれます。使っていないルールを削ると恒久的に入力が減ります

4. GPT-5.3 / 5.4 / 5.5

料金の目安（100万トークンあたり）

モデル入力 / 出力位置づけ
GPT-5.5$5 / $30最上位。複雑な推論・難しい問題向け
GPT-5.4$2.5 / $15標準。日常作業のバランス型
GPT-5.3-Codex$1.75 / $14コーディング特化。プログラミング作業向け

GPT特有の節約ポイント

  • キャッシュ入力の割引：Claudeと同様、繰り返し送られる履歴部分は約10分の1（GPT-5.5で$0.50/100万トークン）になります。同じ会話を続けている間は自動で効きます
  • Batch / Flex処理で半額：「すぐに答えが要らない仕事」（夜間の一括処理など）は、Batch APIを使うと入力・出力とも50%オフ（GPT-5.5なら$2.5/$15）になります
  • ✕ 長すぎる入力に注意：GPT-5.5は入力が27.2万トークンを超えると、そのセッション全体が入力2倍・出力1.5倍の割増料金になります。巨大な資料を丸ごと読ませる前に、分割や要約を検討しましょう
  • 推論の深さ（reasoning effort）を調整：GPTシリーズは「どれだけ深く考えるか」を設定できます。簡単な作業は低め、難しい作業だけ高めにすると出力トークン（＝考えた分も課金対象）を節約できます
  • コーディングならGPT-5.3-Codex：プログラミング作業はGPT-5.5より約3分の1の入力単価で済みます

5. GitHub Copilot

Copilotはトークンではなく「プレミアムリクエスト」という回数制です。1回の依頼につき「モデルごとの係数」分だけ月間枠が減ります。

モデル係数の目安

モデル係数（1依頼あたりの消費）
GPT-5 mini など（同梱モデル）0倍（消費なし）
Sonnet 4.6 / GPT-5.41倍
Opus 4.63倍
Opus 4.7 / GPT-5.57.5倍
Copilotコードレビュー13倍（2026年6月以降）

Copilot特有の節約ポイント

  • ◎ 0倍モデルを使い倒す：要件の確認、方針の相談、ログの分析、タスク分解などの「会話中心の作業」は同梱モデル（0倍）に回すと、枠を一切消費しません
  • ◎ Autoモデル選択で1割引：モデルを自動選択にすると、対象モデルの係数が10%割引になります
  • エージェントモードの内部ループは無料：エージェントが1つの依頼の中で何度もファイルを読み書きしても、消費は最初の1依頼分だけです。細かく何度も指示するより、1回の依頼にまとめる方が得です
  • ✕ 高係数モデルで雑談しない：GPT-5.5（7.5倍）で軽い質問をすると、1倍モデルの7.5回分を一瞬で消費します
  • ✕ コードレビューの多用に注意：1回13倍と最も高コスト。本当に必要なプルリクエストに絞りましょう
  • 2026年6月からの制度変更：回数制（プレミアムリクエスト）から「GitHub AI Credits」という利用量ベースの課金に移行しました。考え方は同じで、「高いモデルほど消費が大きい」構図は変わりません

6. サービス横断の使い分け

3サービスを併用している場合の、コスト効率がよい役割分担の例です。

作業内容おすすめ理由
要件整理・壁打ち・相談Copilotの0倍モデル、またはチャットアプリ枠・トークンをほぼ消費しない
日常のコーディングSonnet 5 / GPT-5.4 / GPT-5.3-Codex（係数1倍クラス）品質と価格のバランスが最良
複雑な設計・難しいバグ調査Opus 4.8 / GPT-5.5高いが、やり直しが減って結果的に安い
夜間の一括処理・急がない大量作業GPTのBatch API50%オフ
コード補完（入力中の提案）Copilot標準補完プレミアム枠を消費しない
考え方のコツ：「上流（考える仕事）は高いモデル、下流（手を動かす仕事）は安いモデル」が基本ですが、相談・確認のような軽い会話はさらに下の無料枠・低単価モデルに回すのが3サービス併用時の最大の節約です。

7. やりがちなムダづかい

ムダづかいパターン対象改善方法
1つの会話で何日も作業を続けるClaude / GPT区切りごとに履歴をリセット（/clear等）
巨大なファイルを丸ごと貼り付ける全サービス必要な部分だけ抜粋。GPT-5.5は27.2万トークン超で割増になる点にも注意
あいまいな指示→聞き返し→修正の繰り返し全サービス最初に目的・条件・完成イメージをまとめて伝える
簡単な質問にも最上位モデルを使う全サービス軽い作業はSonnet / GPT-5.4 / 0倍モデルへ
毎回「コード全体を出力して」と頼むClaude / GPT「変更箇所だけ」と指定（出力単価は入力の5〜6倍）
会話の途中で頻繁にモデルを切り替えるClaude / GPTキャッシュ割引が切れるため、1作業は同じモデルで通す
高係数モデル（7.5倍）で軽い相談をするCopilot相談は0倍の同梱モデルに回す
細かい指示を何度も分けて出すCopilot1依頼にまとめる（エージェントの内部処理は追加消費なし）

8. チェックリスト

作業を始める前に、この6つを確認するだけで大きく変わります。

  • ☐ この作業に合ったモデル・サービスを選んだか（相談→無料枠、普通→標準、難問→最上位）
  • ☐ 前の話題と関係ないなら履歴をリセットしたか
  • ☐ 指示に「目的・条件・完成イメージ」を含めたか
  • ☐ 読ませるファイル・範囲を絞ったか
  • ☐ 回答の形式（簡潔に・変更箇所だけ等）を指定したか
  • ☐ （Copilot）高係数モデルを使う必然性があるか
まとめ：効果が大きい順に、①モデル・サービスの使い分け → ②会話を短く保つ → ③無料枠・低係数モデルの活用（Copilot） → ④入力を絞る → ⑤出力形式の指定 → ⑥キャッシュ・Batchの活用です。まずは①と②から始めるのがおすすめです。
