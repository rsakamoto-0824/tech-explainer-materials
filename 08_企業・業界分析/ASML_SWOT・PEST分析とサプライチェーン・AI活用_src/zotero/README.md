# ASMLのSWOT・PEST分析とサプライチェーン・AI活用の参考文献を Zotero に登録する

## このフォルダのファイル

| ファイル | 役割 |
|---|---|
| `zotero_import_asml.js` | Zotero に貼り付けて実行するスクリプト |
| `manifest.json` | 登録する文献の一覧（37件、添付ファイル37個）。`../make_reference_docs.py` が `../references.json` から作る |
| `result.json` | 実行すると作られる結果（実行前はない） |

## スクリプトがすること

- まだ Zotero に無い文献37件を登録する（ASML の決算発表・投資家向け資料・決算説明会の書き起こし・年次報告書、ASMLとミストラルAIの発表、サプライヤーの資料、オランダ政府・欧州委員会・米国の通商と輸出規制、オランダの事業環境、SEMI・TrendForce などの市場と技術の資料）
- 項目の種類は、決算発表・年次報告書・決算説明会の書き起こしが「レポート」、投資家向け資料が「発表」、そのほかが「Webページ」
- 新しく登録した文献に「未読」タグを付ける。タグは `種別/資料`・`分野/リソグラフィ`・`所属/…`
- 本文ファイル37個（`../sources/` の PDF・XHTML と `../sources/web/` の HTML・テキスト）を、コピーせずリンクで添付する
- テーマのコレクション `05_資料` と、案件のコレクション `2026-10-10_ASML分析`（無ければ1階層で作る）に入れる
- 既存の項目の中身・タグ・コレクションは消さない、書き換えない。何度実行しても二重に登録しない。登録済みだった文献には「未読」タグを付け直さない
- ソニー・サムスンの分析と共通の資料2件（Skadden、Sandler, Travis & Rosenberg）は、先にそちらのスクリプトで登録していれば URL が一致するので新しく作らず、案件のコレクションに追加するだけになる。同じ名前の添付がすでにあれば二重に添付しない（その場合、新規登録は35件・新しい添付は35個になる）
- 取得できなかった asml.com の発表ページ2件は登録しない（同じ発表文を公式資料置き場のPDFと Nasdaq の掲載で登録する）

## 実行手順

1. Zotero を起動する（起動済みならそのまま）
2. スクリプトをクリップボードにコピーする。ターミナルで次を実行する（テキストエディタで開いて全選択・コピーしてもよい）

   ```bash
   pbcopy < "/Users/sakamoto/04_プログラミング/ClaudeCode/GitHub/技術解説資料/08_企業・業界分析/ASML_SWOT・PEST分析とサプライチェーン・AI活用_src/zotero/zotero_import_asml.js"
   ```

3. Zotero のメニューで［ツール］→［開発］（表示によっては［開発者］）→［JavaScriptを実行］を開く
4. 開いた画面の「Run as async」にチェックを入れる（必須）
5. 左のコード欄に貼り付け（⌘V）、「Run」を押す
6. 右の結果欄の `summary` が次のようになれば完了。同じ内容が `result.json` にも保存される
   - 1回目：新規登録 37 件（うち「未読」タグ 37 件）、ファイルのリンク添付 37 件、失敗 0 件（ソニー版かサムスン版を先に実行していれば、新規登録 35 件・再利用 2 件・リンク添付 35 件・添付済み 2 件）
   - 2回目以降：新規登録 0 件、登録済みの再利用 37 件、添付済み 37 件（重複は作られない）
7. 左のコレクション一覧に `2026-10-10_ASML分析` ができ、37件が入っていることを確かめる

## 結果の見方

- `status` が `completed` なら成功。`completed_with_errors` や `failed` のときは `failures` に原因が出る
- `テーマのコレクションが見つかりません: 05_資料` と出たときは、Zotero に `05_資料` コレクションが無い。作ってからもう一度実行する
- `field_warnings` は、項目の種類に無い欄を飛ばした記録。登録そのものは成功している

## 確認済みのこと（2026-10-10）

- ソニー版・サムスン版と同じ処理のスクリプトで、変えたのは読み込む一覧（manifest.json）の場所と名前だけ
- Zotero の動きをまねた環境で2回実行し、1回目は新規37件・未読37件・リンク添付37個・欄の警告0件、2回目は重複なしになることを確かめた
- ソニー版→サムスン版→ASML版の順に実行しても、ASML版は新規35件・再利用2件・リンク添付35個・添付済み2個で、合計109件・添付117個に項目・添付の重複がなく、案件コレクション `2026-10-10_ASML分析` に37件が入ることを確かめた
- 本物の Zotero での実行はまだしていない（Zotero の画面での操作が必要なため）
