# ASMLのSWOT・PEST分析とサプライチェーン・AI活用の生成元

`../ASML_SWOT・PEST分析とサプライチェーン・AI活用.pptx`（34枚・全スライドに発表者ノート付き）を作るためのファイル一式。

## 目的

露光装置の最大手 ASML について、公開情報をもとに PEST分析（政治・経済・社会・技術の外部環境）と SWOT分析（強み・弱み・機会・脅威）を行い、サプライチェーン（部品の調達から顧客まで）を図で示し、AIの活用状況（需要・製品・社内・提携）もわかるようにまとめる。同じフォルダにあるソニー・サムスンの分析（`../Sonyイメージセンサー事業_SWOT・PEST分析_src/`、`../Samsungイメージセンサー事業_SWOT・PEST分析_src/`）と同じ作り方にした。

## ファイル

| ファイル | 役割 |
|---|---|
| `build_deck.js` | pptxgenjs でスライドを組み立てる。数値と出典はこの中に直接書いてある。補助関数の多くはサムスン版と同じで、配色とモチーフ（ウエハーとチップ）は ASML 用に変えた |
| `references.json` | 参考文献の正本（39件：スライドに載せる37件＋取得できなかった asml.com の発表ページ2件）。スライドの参考文献、`参考文献リンク.md`、`参考文献リンク_一覧.txt`、`zotero/manifest.json` はここから作る |
| `make_reference_docs.py` | `references.json` から `参考文献リンク.md`、`参考文献リンク_一覧.txt`、`zotero/manifest.json` を作る |
| `参考文献リンク.md` | 参考文献・参考リンクの一覧（保存済み・未取得の別と理由） |
| `参考文献リンク_一覧.txt` | メール添付用の短い一覧（番号・発行元・日付・題名・URL）。Gmail の下書きに添付した |
| `fetch_sources.py` | 参考文献の本文（PDF・XHTML・HTML）を `sources/` と `sources/web/` に保存する。保存済みのものは取り直さない |
| `postprocess.py` | フォント指定の修正（和文 BIZ UDGothic・欧文 Arial、日本語の文字セット）、段落プロパティの重複削除、ノートマスターと Content_Types の正規化、図形IDの振り直し、ZIP の再圧縮（ソニー版・サムスン版と同じ処理） |
| `check_deck.py` | 生成物の機械検査（Content_Typesの部品の実在、全スライドのノート、文字セット、線種、図形のはみ出し、仮置きの文字、外部リンク数） |
| `sources/` | ASML の決算発表・投資家向け資料・決算説明会の書き起こし（PDF）と年次報告書（戦略報告の章のPDF、全文のXHTML） |
| `sources/web/` | 本文を保存した公開Webページ（HTML 28ファイル）と、ブラウザで閲覧した ASML の投資家向けページの本文（テキスト1ファイル） |
| `zotero/` | 参考文献を Zotero に登録するスクリプトと一覧。実行手順は `zotero/README.md` |

## 作り直す手順

Node.js に `pptxgenjs`（4.0.1）、Python 3 に `python-pptx` が入っている前提。このフォルダで実行する。

```bash
NODE_PATH="$(npm root -g)" node build_deck.js deck_raw.pptx
```

```bash
python3 postprocess.py deck_raw.pptx deck.building.pptx
```

```bash
python3 check_deck.py deck.building.pptx 34
```

pptx スキルの `validate.py` での検証、LibreOffice での全スライドの表示確認、PowerPoint での再オープン確認が済んでから、`deck.building.pptx` を `../ASML_SWOT・PEST分析とサプライチェーン・AI活用.pptx` へ移す。PowerPoint で開いている間は上書きしない。

参考文献を直したときは、`references.json` を直してから次を実行し、上の手順でスライドも作り直す。

```bash
python3 make_reference_docs.py
```

## 注意

- 数値はすべて公開資料からの引用（確認日 2026-10-10）。ASML の決算は暦年（1〜12月）で、金額は米国会計基準のユーロ建ての開示値。億ユーロへの換算、比率（ツァイスからの購入額が売上原価に占める規模、オランダの従業員・固定資産の比率、見通しの上昇率など）は本資料で計算した
- 2026年7〜9月期の決算（2026年10月14日に発表予定。ASMLの投資家向けページで確認）は反映していない
- 米中の休戦の期限（中国のレアアース規制と米国の50%ルールの停止）は、ASML の年次報告書の記載（いずれも2026年11月10日まで）に合わせた。ガリウムなどの対米規制の停止は2026年11月27日まで（Clark Hill）
- asml.com の Web ページはスクリプトからの取得を拒否した（HTTP 403）。ボット対策は回避せず、同じ発表文を ASML の公式資料置き場（ourbrand.asml.com）のPDFや、配信先の MFN・Nasdaq の掲載から保存した。年次報告書の全文は ESEF 形式の提出書類（filings.xbrl.org）を保存した
- ASML の投資家向けページ（investor.asml.com の Quarterly results）はスクリプトからは接続できなかったため、アプリ内のブラウザで閲覧し、本文を `sources/web/` にテキストで保存した
- 通商の2件（Skadden、Sandler, Travis & Rosenberg）は、ソニー版の `sources/web/` に 2026-09-27 に保存したファイルをコピーした。フォルダを単独で動かせるよう、`fetch_sources.py` にも URL を載せている
- 報道に基づく内容（MATCH法案の見通し、米国の対オランダ要求、中国のEUV試作機、TSMCのHigh NA見送り、EUV装置の中国流入の疑いなど）は、スライドに「報道」と書いて事実と区別した
- 「本資料の見方」「本資料の評価」と書いた項目（PESTの符号、影響度マップの配置、クロスSWOT、打ち手の評価、代わりのききやすさ）は、出典の事実をもとにした整理で、出典そのものの記載ではない
- 社内の情報は使っていない。投資判断を目的とした資料ではない
- 参考文献スライドのリンクは英字のドメイン名に付けた。和文にリンクを付けると、LibreOffice の確認画像で別の字体に置き換わるため
