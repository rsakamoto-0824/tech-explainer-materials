# ソニーのイメージセンサー事業 SWOT・PEST分析の参考文献を Zotero に登録する

## このフォルダのファイル

| ファイル | 役割 |
|---|---|
| `zotero_import_sony_cis.js` | Zotero に貼り付けて実行するスクリプト |
| `manifest.json` | 登録する文献の一覧（50件、添付ファイル56個）。`../make_reference_docs.py` が `../references.json` から作る |
| `result.json` | 実行すると作られる結果（実行前はない） |

## スクリプトがすること

- まだ Zotero に無い文献50件を登録する
  - 本文を保存した資料45件（ソニーセミコンダクタソリューションズの発表、経済産業省、Yole Group、IDC、EE Times Japan など）
  - 閲覧のみで本文を保存していない、米SEC提出のソニー決算資料5件（URLだけを登録）
- 新しく登録した文献に「未読」タグを付ける
- 本文ファイル56個（`../sources/` の PDF・HTML）を、コピーせずリンクで添付する。複数ページの記事は全ページを添付する
- テーマのコレクション `05_資料` と、案件のコレクション `2026-09-27_Sonyイメージセンサー事業分析`（無ければ1階層で作る）に入れる
- 既存の項目の中身・タグ・コレクションは消さない、書き換えない。何度実行しても二重に登録しない。登録済みだった文献には「未読」タグを付け直さない

## 実行手順

1. Zotero を起動する（起動済みならそのまま）
2. スクリプトをクリップボードにコピーする。ターミナルで次を実行する（テキストエディタで開いて全選択・コピーしてもよい）

   ```bash
   pbcopy < "/Users/sakamoto/04_プログラミング/ClaudeCode/GitHub/技術解説資料/08_企業・業界分析/Sonyイメージセンサー事業_SWOT・PEST分析_src/zotero/zotero_import_sony_cis.js"
   ```

3. Zotero のメニューで［ツール］→［開発］（表示によっては［開発者］）→［JavaScriptを実行］を開く
4. 開いた画面の「Run as async」にチェックを入れる（必須）
5. 左のコード欄に貼り付け（⌘V）、「Run」を押す
6. 右の結果欄の `summary` が次のようになれば完了。同じ内容が `result.json` にも保存される
   - 1回目：新規登録 50 件（うち「未読」タグ 50 件）、ファイルのリンク添付 56 件、失敗 0 件
   - 2回目以降：新規登録 0 件、登録済みの再利用 50 件、添付済み 56 件（重複は作られない）
7. 左のコレクション一覧に `2026-09-27_Sonyイメージセンサー事業分析` ができ、50件が入っていることを確かめる

## 結果の見方

- `status` が `completed` なら成功。`completed_with_errors` や `failed` のときは `failures` に原因が出る
- `テーマのコレクションが見つかりません: 05_資料` と出たときは、Zotero に `05_資料` コレクションが無い。作ってからもう一度実行する
- `field_warnings` は、項目の種類に無い欄を飛ばした記録。登録そのものは成功している
