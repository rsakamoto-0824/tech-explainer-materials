# ソニーのイメージセンサー事業 SWOT・PEST分析の生成元

`../Sonyイメージセンサー事業_SWOT・PEST分析.pptx`（27枚・全スライドに発表者ノート付き）を作るためのファイル一式。

## 目的

ソニーグループのイメージセンサー事業（I&SS分野）について、公開情報をもとに PEST分析（政治・経済・社会・技術の外部環境）と SWOT分析（強み・弱み・機会・脅威）を行い、クロスSWOT・打ち手の評価・今後の注目点までをまとめる。

## 構成（27枚）

| 部 | スライド |
|---|---|
| 導入 | 1 表紙／2 この資料について／3 エグゼクティブサマリー |
| 現在地 | 4 事業の概要／5 業績の推移（2021〜2026年度予想）／6 市場でのポジション／7 売上構成と顧客／8 技術の歩み／9 直近の出来事 |
| PEST分析 | 10 全体像／11 政治／12 経済／13 社会／14 技術／15 影響度マップ |
| SWOT分析 | 16 全体像／17 強み／18 弱み／19 機会／20 脅威／21 クロスSWOT |

| 付録 | 25 用語集／26〜27 参考文献（50件） |

## ファイル

| ファイル | 役割 |
|---|---|
| `build_deck.js` | pptxgenjs でスライドを組み立てる。数値と出典はこの中に直接書いてある |
| `references.json` | 参考文献の正本（53件：スライドに載せる50件＋取得できなかったソニーIR資料3件）。スライドの参考文献、`参考文献リンク.md`、`zotero/manifest.json` はここから作る |
| `make_reference_docs.py` | `references.json` から `参考文献リンク.md`、`参考文献リンク_一覧.txt`、`zotero/manifest.json` を作る |
| `参考文献リンク_一覧.txt` | メール添付用の短い一覧（番号・発行元・日付・題名・URL）。Gmail の下書きに添付した |
| `fetch_sources.py` | 参考文献の本文（公開Webページ・PDF）を `sources/` に保存する。保存済みのものは取り直さない |
| `postprocess.py` | フォント指定の修正（和文 BIZ UDGothic・欧文 Arial、日本語の文字セット）、段落プロパティの重複削除、ノートマスターと Content_Types の正規化、図形IDの振り直し、不正な線種の検査、ZIP の再圧縮 |
| `check_deck.py` | 生成物の機械検査（Content_Typesの部品の実在、全スライドのノート、文字セット、線種、図形のはみ出し、仮置きの文字、外部リンク数） |
| `参考文献リンク.md` | 参考文献・参考リンクの一覧（保存・閲覧のみ・未取得の別と理由） |
| `sources/` | 本文を保存した公開資料（PDF）と、Webページの保存（`sources/web/`、HTML） |
| `zotero/` | 参考文献を Zotero に登録するスクリプトと一覧。実行手順は `zotero/README.md` |

## 作り直す手順

Node.js に `pptxgenjs`（4.0.1）、Python 3 に `python-pptx` が入っている前提。このフォルダで実行する。

```bash
NODE_PATH="$(npm root -g)" node build_deck.js deck_raw.pptx
python3 postprocess.py deck_raw.pptx deck.building.pptx
python3 check_deck.py deck.building.pptx 27
```

pptx スキルの `validate.py` での検証、LibreOffice での全スライドの表示確認、PowerPoint での再オープン確認が済んでから、`deck.building.pptx` を `../Sonyイメージセンサー事業_SWOT・PEST分析.pptx` へ移す。PowerPoint で開いている間は上書きしない。

参考文献を直したときは、`references.json` を直してから次を実行し、上の手順でスライドも作り直す。

```bash
python3 make_reference_docs.py
```

## 注意

- 数値はすべて公開資料からの引用（確認日 2026-09-27）。ソニーの年度は4月〜翌3月（2025年度＝2025年4月〜2026年3月）。業績は国際会計基準（IFRS）にそろえるため2021年度から示した
- ソニーの決算資料は、米SECに提出された英語版をアプリ内ブラウザで閲覧して数値を確認した。SECはスクリプトからの取得に連絡先メールアドレス入りのUser-Agentを求めるため、ファイルは保存していない
- sony.com の資料（事業説明会のPDF、決算の補足資料）は自動取得が拒否され、アプリ内ブラウザでも開けなかった。内容は EE Times Japan の報道で確認し、出典にもそう書いた
- 世界シェアは調査会社によって数値が違う（Yole：約50%、日経業界地図2027年版：53.6%、ソニー自社調べ：2024年53%）。スライド6では両方を示した
- AppleがSamsung製のイメージセンサーを採用するという点は、Appleの発表（「新しいチップ製造技術」）と報道・アナリストの推計に基づく。確定した事実ではない
- 「本資料の評価」「本資料による」と書いた項目（PESTの符号、影響度マップの配置、クロスSWOT、打ち手の評価、注目点の時期の推定）は、出典の事実をもとにした整理で、出典そのものの記載ではない
- 社内の情報は使っていない。投資判断を目的とした資料ではない
- 参考文献スライドのリンクは英字のドメイン名に付けた。和文にリンクを付けると、LibreOffice の確認画像で別の字体（等幅風）に置き換わるため（XML上のフォント指定は正しい）
