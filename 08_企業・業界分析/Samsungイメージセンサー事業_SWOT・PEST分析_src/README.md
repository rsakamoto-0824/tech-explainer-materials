# サムスン電子のイメージセンサー事業 SWOT・PEST分析の生成元

`../Samsungイメージセンサー事業_SWOT・PEST分析.pptx`（27枚・全スライドに発表者ノート付き）を作るためのファイル一式。

## 目的

サムスン電子のイメージセンサー事業（DS部門 System LSI事業部の「ISOCELL」）について、公開情報をもとに PEST分析（政治・経済・社会・技術の外部環境）と SWOT分析（強み・弱み・機会・脅威）を行い、クロスSWOT・打ち手の評価・今後の注目点までをまとめる。同じフォルダにあるソニーの分析（`../Sonyイメージセンサー事業_SWOT・PEST分析_src/`）と同じ構成・同じ作り方にした。

## ファイル

| ファイル | 役割 |
|---|---|
| `build_deck.js` | pptxgenjs でスライドを組み立てる。数値と出典はこの中に直接書いてある。補助関数と配色はソニー版と同じ |
| `references.json` | 参考文献の正本（42件：スライドに載せる41件＋取得できなかった米商務省の発表1件）。スライドの参考文献、`参考文献リンク.md`、`参考文献リンク_一覧.txt`、`zotero/manifest.json` はここから作る |
| `make_reference_docs.py` | `references.json` から `参考文献リンク.md`、`参考文献リンク_一覧.txt`、`zotero/manifest.json` を作る |
| `参考文献リンク_一覧.txt` | メール添付用の短い一覧（番号・発行元・日付・題名・URL）。Gmail の下書きに添付した |
| `fetch_sources.py` | 参考文献の本文（公開Webページ）を `sources/web/` に保存する。保存済みのものは取り直さない |
| `postprocess.py` | フォント指定の修正（和文 BIZ UDGothic・欧文 Arial、日本語の文字セット）、段落プロパティの重複削除、ノートマスターと Content_Types の正規化、図形IDの振り直し、不正な線種の検査、ZIP の再圧縮（ソニー版と同じ処理） |
| `check_deck.py` | 生成物の機械検査（Content_Typesの部品の実在、全スライドのノート、文字セット、線種、図形のはみ出し、仮置きの文字、外部リンク数） |
| `参考文献リンク.md` | 参考文献・参考リンクの一覧（保存済み・未取得の別と理由） |
| `sources/web/` | 本文を保存した公開資料（HTML、44ファイル） |
| `zotero/` | 参考文献を Zotero に登録するスクリプトと一覧。実行手順は `zotero/README.md` |

## 作り直す手順

Node.js に `pptxgenjs`（4.0.1）、Python 3 に `python-pptx` が入っている前提。このフォルダで実行する。

```bash
NODE_PATH="$(npm root -g)" node build_deck.js deck_raw.pptx
python3 postprocess.py deck_raw.pptx deck.building.pptx
python3 check_deck.py deck.building.pptx 27
```

pptx スキルの `validate.py` での検証、LibreOffice での全スライドの表示確認、PowerPoint での再オープン確認が済んでから、`deck.building.pptx` を `../Samsungイメージセンサー事業_SWOT・PEST分析.pptx` へ移す。PowerPoint で開いている間は上書きしない。

参考文献を直したときは、`references.json` を直してから次を実行し、上の手順でスライドも作り直す。

```bash
python3 make_reference_docs.py
```

## 注意

- 数値はすべて公開資料からの引用（確認日 2026-09-28）。サムスンの決算は暦年（1〜12月）で、金額はウォン建ての開示値
- サムスンはイメージセンサー単独の売上・利益を公表していない。事業の状況は、調査会社のシェアと、決算発表での System LSI 事業部の説明から読んだ
- 世界シェアは調査会社によって数値も順位も違う（Yole：2位を維持・売上は横ばい、日経業界地図2027年版：13.2%で3位、TSR：OmniVisionが初めて上回り2位）。スライド5で両方を示した
- Yole のシェアの推移のうち 2021年の22%は、「2022年は前年比3ポイント減の19%」（EE Times Japan 2023-07-27）から計算した値。2024年以降の数値は Yole が公表していない
- 「全社の営業利益の99.7%をDS部門が稼ぐ」は、決算発表の数値（89.2兆ウォン÷89.5兆ウォン）から本資料で計算した
- AppleがSamsung製のイメージセンサーを採用するという点は、Appleの発表（「新しいチップ製造技術」）と報道・アナリストの推計に基づく。確定した事実ではない。流出データを情報源とする報道（Sammy Fans 2026-07-03）は、信頼性が不明と明記した
- DIGITIMES（2026-04-16）の人材流出の記事は有料で、公開部分（冒頭）だけを確認した
- 米商務省のCHIPS法の支援の発表（2024年12月）は、スクリプトからの取得が拒否された（HTTP 403）。同じ内容を載せた NIST の CHIPS のページを保存して使った
- ソニーの分析と共通の資料17件（18ファイル）は、ソニー版の `sources/web/` に 2026-09-27 に保存したファイルをコピーした。フォルダを単独で動かせるよう、`fetch_sources.py` にも URL を載せている
- 「本資料の評価」「本資料の見方」と書いた項目（PESTの符号、影響度マップの配置、クロスSWOT、打ち手の評価、注目点の時期の推定）は、出典の事実をもとにした整理で、出典そのものの記載ではない
- 社内の情報は使っていない。投資判断を目的とした資料ではない
- 参考文献スライドのリンクは英字のドメイン名に付けた。和文にリンクを付けると、LibreOffice の確認画像で別の字体（等幅風）に置き換わるため（XML上のフォント指定は正しい）
