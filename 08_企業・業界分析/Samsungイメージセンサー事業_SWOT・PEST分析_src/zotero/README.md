# サムスン電子のイメージセンサー事業 SWOT・PEST分析の参考文献を Zotero に登録する

## このフォルダのファイル

| ファイル | 役割 |
|---|---|
| `zotero_import_samsung_cis.js` | Zotero に貼り付けて実行するスクリプト |
| `manifest.json` | 登録する文献の一覧（41件、添付ファイル44個）。`../make_reference_docs.py` が `../references.json` から作る |
| `result.json` | 実行すると作られる結果（実行前はない） |

## スクリプトがすること

- まだ Zotero に無い文献41件を登録する（サムスン電子の決算・製品発表、Yole Group・IDC・TechInsights などの調査会社、EE Times Japan・THE ELEC・DIGITIMES などの業界メディア、AppleとSamsungに関する報道、米国・韓国の政策、競合のソニーの発表）
- 新しく登録した文献に「未読」タグを付ける
- 本文ファイル44個（`../sources/web/` の HTML）を、コピーせずリンクで添付する。複数ページの記事は全ページを添付する
- テーマのコレクション `05_資料` と、案件のコレクション `2026-09-28_Samsungイメージセンサー事業分析`（無ければ1階層で作る）に入れる
- 既存の項目の中身・タグ・コレクションは消さない、書き換えない。何度実行しても二重に登録しない。登録済みだった文献には「未読」タグを付け直さない
- ソニーの分析（2026-09-27）と共通の資料17件は、ソニー版のスクリプトで先に登録していれば URL が一致するので新しく作らず、案件のコレクションに追加するだけになる。ファイルも、同じ名前の添付がすでにあれば二重に添付しない（その場合、新規登録は24件・新しい添付は26個になる）
- 取得できなかった米商務省の発表（2024年12月）は登録しない

## 実行手順

1. Zotero を起動する（起動済みならそのまま）
2. スクリプトをクリップボードにコピーする。ターミナルで次を実行する（テキストエディタで開いて全選択・コピーしてもよい）

   ```bash
   pbcopy < "/Users/sakamoto/04_プログラミング/ClaudeCode/GitHub/技術解説資料/08_企業・業界分析/Samsungイメージセンサー事業_SWOT・PEST分析_src/zotero/zotero_import_samsung_cis.js"
   ```

3. Zotero のメニューで［ツール］→［開発］（表示によっては［開発者］）→［JavaScriptを実行］を開く
4. 開いた画面の「Run as async」にチェックを入れる（必須）
5. 左のコード欄に貼り付け（⌘V）、「Run」を押す
6. 右の結果欄の `summary` が次のようになれば完了。同じ内容が `result.json` にも保存される
   - 1回目：新規登録 41 件（うち「未読」タグ 41 件）、ファイルのリンク添付 44 件、失敗 0 件（ソニー版を先に実行していれば、新規登録 24 件・再利用 17 件・リンク添付 26 件・添付済み 18 件）
   - 2回目以降：新規登録 0 件、登録済みの再利用 41 件、添付済み 44 件（重複は作られない）
7. 左のコレクション一覧に `2026-09-28_Samsungイメージセンサー事業分析` ができ、41件が入っていることを確かめる

## 結果の見方

- `status` が `completed` なら成功。`completed_with_errors` や `failed` のときは `failures` に原因が出る
- `テーマのコレクションが見つかりません: 05_資料` と出たときは、Zotero に `05_資料` コレクションが無い。作ってからもう一度実行する
- `field_warnings` は、項目の種類に無い欄を飛ばした記録。登録そのものは成功している
