# 計測点の最適配置（D最適・I最適）提案資料の生成元

`../重ね合わせ計測点の最適配置_D最適・I最適の提案.pptx`（29枚・全スライドに発表者ノート付き）を作るためのファイル一式。

## 目的

親資料「重ね合わせ精度とコストの両立」スライド14（②計測最適化・追加提案①「モデルに合わせた点の配置」）を、詳しい提案資料にする。Shot内のマーク位置とウェーハ上で測るShotを、補正式から計算して決めることを提案し、合成データで効果と注意点を示す。

## 資料の構成

| スライド | 内容 |
|---|---|
| 1〜4 | 表紙、要旨、背景（点数と置き方の影響、文献）、位置づけ（親資料と以前の検討） |
| 5〜9 | 基本（1次元の例、ノイズが補正に乗る倍率κ）、最適化の基準（D・I・G）、手順（点交換法）、対象の補正式 |
| 10〜17 | 合成データ：Shot内の配置の比較、点数とκ、同じκに必要な点数、κマップ、置ける場所の制約、ウェーハ面内のShot選び、補正式にない形、点の欠け |
| 18〜25 | 使い分け、業界の報告例、効果の見積もり方、進め方、必要なもの、判定の基準、リスクと対策、他の提案との組み合わせ |
| 26〜29 | まとめ、付録（式・用語集・参考文献） |

## ファイル

| ファイル | 役割 |
|---|---|
| `demo_sampling_design.py` | 合成データの試算（約1分）。以前の検討のκの照合、Shot内の配置（格子・散らばり・ランダム・D最適・I最適）、置ける場所の制約、ウェーハ面内のShot選び、補正式にない形・点の欠けへの強さを計算し、`demo_results.json` に書き出す |
| `demo_results.json` | 上のスクリプトの出力。スライドとノートの数値はすべてここから取る |
| `build_deck.js` | pptxgenjs でスライドを組み立てる。参考文献（`REFERENCES`）もここに書いてある |
| `postprocess.py` | フォント指定の修正、段落プロパティの重複削除、ノートマスターと Content_Types の正規化、図形IDの振り直し、不正な線種の検査、ZIP の再圧縮（親資料と同じ内容） |
| `check_deck.py` | 生成物の機械検査（親資料と同じ内容） |
| `参考文献リンク.md` | 参考文献の一覧（DOIのリンクと、本文を確認した手元のPDF）と関連資料 |

## 作り直す手順

Python 3.14 に NumPy、Node.js に pptxgenjs 4.0.1、Python に python-pptx が入っている前提。このフォルダで実行する。

```bash
python3 demo_sampling_design.py
NODE_PATH="$(npm root -g)" node build_deck.js deck_raw.pptx
python3 postprocess.py deck_raw.pptx deck.building.pptx
python3 check_deck.py deck.building.pptx 29
```

pptx スキルの `validate.py` での検証、LibreOffice での全スライドの表示確認、PowerPoint での再オープン確認が済んでから、`deck.building.pptx` を `../重ね合わせ計測点の最適配置_D最適・I最適の提案.pptx` へ移す。PowerPoint で開いている間は上書きしない（`~$` で始まるロックファイルがあれば中止する）。

## 計算の前提

- κ（ノイズが補正に乗る倍率）＝ 評価点で平均した予測分散の平方根 ÷ 計測ノイズσ（X・Yの式で2乗平均）。以前の検討（`GitHub/high-order-correction-report` の `expected_error_ridge.m`）と同じ定義で、Shot端を含む7×11格子のκ（線形0.187・ASML式0.283・Nikon式0.382）を差0.00001未満で再現した
- Shot内の補正式は、露光機メーカーごとの式（ASML・Canon・Nikon）の項と係数番号をそのまま使った。x・y はShot中心基準の座標 [mm]、Shotは 26×33 mm、評価点は約1 mm間隔の27×34点
- 候補の場所は、Shot全面（評価点と同じ1 mm格子）、Shot外周のスクライブだけ、ダイ間のスクライブもある場合（2×3ダイの例）の3通り
- ウェーハ面内は、ウェーハ座標の3次の式（X・Y各10項）。候補は有効なマーク（半径150 mm未満）が3つ以上のShot（親資料の通常の計測と同じ条件）で、選んだShotの有効なマークをすべて測る。評価点は半径150 mm未満の5 mm格子
- 最適化は点交換法（1点ずつ、基準が最もよくなる候補に入れ替える。初期値を変えて10回）。「端が抜けた格子」は、以前の検討で使った14×22格子を1点おきに間引いた7×11点
- 補正式にない形は、Shot内は6次までの式にない項、ウェーハ面内は4〜5次の項を、評価点でのRMS 0.3 nm の正規乱数とし、取り残しの期待値を式で計算した
- 乱数の種はデモごとに固定しているので、同じバージョンの NumPy なら同じ数値になる（2026-09-28 に Python 3.14.6・NumPy 2.4.6 で実行）

## 注意

- 数値はすべて合成データでの試算で、考え方の確認用。効果の大きさは自社のデータ（候補ターゲット、σ、取り残し、計測時間）で検証が必要
- Shot端を含む等間隔の格子はもともと良い配置で、そこからのI最適による削減は1割弱（ASML式・Nikon式）。補正式にない形が大きいと格子が有利になる場合がある（スライド16）。資料ではこの点を隠さずに書いている
- 文献10件は、手元の論文ライブラリの本文で内容と数値を確認した
