# 重ね合わせ精度とコストの両立 資料の生成元

`../重ね合わせ精度とコストの両立_技術進化コンセプトと具体案.pptx`（33枚・全スライドに発表者ノート付き）を作るためのファイル一式。

## 目的

ラインの重ね合わせ（OVL）精度とコストのトレードオフを改善するため、ユーザーのメモを基に、6つの技術観点（①制御最適化 ②計測最適化 ③傾向監視 ④仮想測定 ⑤異常検知 ⑥測定技術）の技術進化のコンセプトと具体案をまとめる。各領域には、メモ以外の追加提案も加える。

## 資料の構成

| スライド | 内容 |
|---|---|
| 1〜8 | 表紙、結論、背景（4種類のコスト）、コンセプト（トレードオフ曲線を動かす）、考え方、6領域の関係、進化の道筋、メモの14論点と該当スライド |
| 9〜25 | 6領域ごとに「メモからの具体案」と「追加提案」。①②③④は合成データでの確認を含む |
| 26〜29 | 領域の連携の例（外周の歪み）、優先順位、評価指標と検証の進め方、リスクと対策 |
| 30〜33 | まとめ、用語集、参考文献（30件） |

提案カードの印：灰色の「メモ」はメモ由来、金色の「追加」はこの資料での追加提案。

## ファイル

| ファイル | 役割 |
|---|---|
| `demo_overlay_cost.py` | 合成データのデモを計算し、`demo_results.json` に書き出す（約12秒）。①外周だけCPE ②領域別の計測頻度 ③補正パラメータの動きからの想定範囲 ④少ないアライメント点からの面内推定 ⑤サンキー図の例 |
| `demo_results.json` | 上のスクリプトの出力。スライドのデモの数値と、スライド・ノートの文中の数値はすべてここから取る |
| `build_deck.js` | pptxgenjs でスライドを組み立てる。参考文献（`REFERENCES`）もここに書いてある |
| `postprocess.py` | フォント指定の修正（和文 BIZ UDGothic・欧文 Arial、日本語の文字セット）、段落プロパティの重複削除、ノートマスターと Content_Types の正規化、図形IDの振り直し、不正な線種の検査、ZIP の再圧縮（ロードマップ資料と同じ内容） |
| `check_deck.py` | 生成物の機械検査（Content_Typesの部品の実在、全スライドのノート、文字セット、線種、図形のはみ出し、仮置きの文字、外部リンク数） |
| `参考文献リンク.md` | 参考文献の一覧（DOIのリンクと、本文を確認した手元のPDF） |

## 作り直す手順

Python 3.14 に NumPy、Node.js に pptxgenjs 4.0.1、Python に python-pptx が入っている前提。このフォルダで実行する。

```bash
python3 demo_overlay_cost.py
NODE_PATH="$(npm root -g)" node build_deck.js deck_raw.pptx
python3 postprocess.py deck_raw.pptx deck.building.pptx
python3 check_deck.py deck.building.pptx 33
```

pptx スキルの `validate.py` での検証、LibreOffice での全スライドの表示確認、PowerPoint での再オープン確認が済んでから、`deck.building.pptx` を `../重ね合わせ精度とコストの両立_技術進化コンセプトと具体案.pptx` へ移す。PowerPoint で開いている間は上書きしない（`~$` で始まるロックファイルがあれば中止する）。

## 注意

- デモはすべて合成データで、考え方が成り立つかの確認用。効果の大きさは自社のデータで検証が必要。社内の情報は使っていない
- 座標はウェーハ中心を原点とする mm、ずれは nm、有効な点は半径 150 mm 未満（Overlay計測ルールに合わせた）。ショットは 26×33 mm・106ショット、1ショット4マーク
- 評価指標は X・Y 別の |平均|+3σ の大きい方
- CPE はショットごとの1次の補正（dx = k1 + k3·x + k5·y、dy = k2 + k4·y + k6·x の6項）として計算した。マークが2点以下のショットは並進だけ。装置メーカーの高次補正の式は使っていない
- 乱数の種はデモごとに固定しているので、同じバージョンの NumPy なら同じ数値になる（2026-09-28 に Python 3.14.6・NumPy 2.4.6 で実行）
- 領域別の計測頻度のデモ（②）は、乱数ではなくカルマンフィルタの定常誤差の式で計算している
- 参考文献30件のうち29件は、手元の論文ライブラリの本文で数値を確認した。Graff ほか（CIRP Annals 2023）だけは本文を入手できず、抄録で確認した
- 図形で描いたグラフ（系列ごとに X 値が違う折れ線、対数目盛り、サンキー図、ウェーハ図）は、値を変えるときは `demo_results.json` を作り直してから再生成する
