# 重ね合わせ制御ロードマップの参考文献を Zotero に登録する

## このフォルダのファイル

| ファイル | 役割 |
|---|---|
| `zotero_import_roadmap.js` | Zotero に貼り付けて実行するスクリプト |
| `manifest.json` | 登録する文献の一覧（新規41件、登録済みで案件に含める23件） |
| `result.json` | 実行すると作られる結果（実行前はない） |

## スクリプトがすること

- まだ Zotero に無い文献41件を登録する（論文4本、年表・ロードマップ・特許・各社の発表など37件）
  - 「未読」タグを付ける
  - 本文ファイル32件（`../sources/` の PDF・HTML）を、コピーせずリンクで添付する
  - テーマのコレクション（論文は `01_半導体プロセス`、資料は `05_資料`）に入れる
- 案件のコレクション `2026-09-26_重ね合わせ制御ロードマップ` を作り（1階層）、新規の41件と、この案件で参照した登録済みの論文22本を入れる
  - 登録済みの論文には「未読」タグを付けない
- 既存の項目の中身・タグ・コレクションは消さない、書き換えない。何度実行しても二重に登録しない

## 実行手順

1. Zotero を起動する（起動済みならそのまま）
2. スクリプトをクリップボードにコピーする。ターミナルで次を実行する（テキストエディタで開いて全選択・コピーしてもよい）

   ```bash
   pbcopy < "/Users/sakamoto/04_プログラミング/ClaudeCode/GitHub/技術解説資料/04_露光・Overlay/重ね合わせ制御の進化と展望_ロードマップ_src/zotero/zotero_import_roadmap.js"
   ```

3. Zotero のメニューで［ツール］→［開発］（表示によっては［開発者］）→［JavaScriptを実行］を開く
4. 開いた画面の「Run as async」にチェックを入れる（必須）
5. 左のコード欄に貼り付け（⌘V）、「Run」を押す
6. 右の結果欄の `summary` が次のようになれば完了。同じ内容が `result.json` にも保存される
   - 1回目：新規登録 41 件（うち「未読」タグ 41 件）、登録済みの参考文献を案件コレクションへ 22 件、ファイルのリンク添付 32 件、失敗 0 件
   - 2回目以降：新規登録 0 件、登録済みの再利用 41 件、添付済み 32 件（重複は作られない）
7. 左のコレクション一覧に `2026-09-26_重ね合わせ制御ロードマップ` ができ、63件（新規41＋登録済み22）が入っていることを確かめる

## 結果の見方

- `status` が `completed` なら成功。`completed_with_errors` や `failed` のときは `failures` に原因が出る
- `existing_references_not_found` に `macmillen1982` が出るのは想定どおり。MacMillen & Ryden (1982) は論文ライブラリにPDFがあるがZoteroに未登録のため。SCK論文の取り込み（`~/00_仕事/01_SCK/06_論文/tools/`）で登録された後にもう一度実行すると、案件コレクションに入る
- `field_warnings` は、項目の種類に無い欄を飛ばした記録。登録そのものは成功している
- 「未読」タグに色を割り当てると（タグ一覧で右クリック→色を割り当て）、未読の文献に色の点が付いて見分けやすい

- 使っている欄の名前と作成者の種類が、インストールされている Zotero 10.0.4 の項目定義（schema version 44）にすべてあることを確かめた
